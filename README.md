# replacinator

![Replacinator: Find & replace in form fields.](static/github/hero.png)

A minimal Chrome extension to find and replace input values on web pages.

## Screenshot

The extension currently supports the light theme only.

![Replacinator interface with Find set to "This", Replace with set to "That", and a Replace button.](static/github/screenshot.png)

## Demo video

Watch Replacinator correct a fruit catalog's weight units from `kilogram` to `gram`.

![Replacinator demo: replacing kilogram with gram in the fruit catalog's unit fields.](static/github/video.gif)
